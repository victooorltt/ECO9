# ECO-9

Videojuego de exploración en realidad virtual realizado con **Unity 2020.3.49** para **Google Cardboard**, como práctica de la asignatura *Realidad y Accesibilidad Aumentadas* de la Universidad de Oviedo.

## Vídeo de demostración

## Descarga del juego y del proyecto

📦 **[Release v1.0: APK y unitypackage](https://github.com/victooorltt/ECO9/releases/tag/v1.0)**

- **ECO9.apk**: compilación del juego para Android.
- **ECO9.unitypackage**: escenas de Unity con sus dependencias. Para importar el paquete, utiliza un proyecto con la configuración de Google VR/Cardboard necesaria.

## ¿En qué consiste?

Tras un accidente en el planeta ECO-9, el jugador debe activar **tres balizas** para enviar una señal de rescate antes de que transcurran tres minutos. Le acompaña **ORBI**, un robot que guía el recorrido mediante diálogos.

El escenario incluye un terreno creado con **Terrain**, exploración en primera persona con **CharacterController**, un dron de vigilancia, generadores auxiliares y una cinemática de rescate realizada con **Timeline**.

## Controles

- **Mirada:** orientación de la cabeza en VR; en el editor se simula con Alt + ratón.
- **Desplazamiento:** joystick de un mando compatible; WASD en el editor.
- **Interacción:** apuntar hacia el objeto y confirmar con el control de interacción disponible.

## Recursos utilizados

Modelos y recursos de Unity Asset Store, incluidos los empleados para ORBI, el escenario espacial, las rocas y la nave de rescate.
